# S3-06 — Khách không đến

Nhánh độc lập từ nền chung e2e1d92; không chứa thao tác check-in hoặc thông báo thợ S3-03.
Nền chung chỉ gồm schema lịch hẹn, audit và cookie/JWT; dùng chung migration để hai nhánh có thể tích hợp.

Lễ tân/Chủ tiệm/Admin mở /NoShows. Sau 30 phút giờ hẹn, Pending/Confirmed chưa check-in có thể đánh dấu NoShow.
Giải phóng khung giờ, cộng số lần không đến theo điện thoại, ghi actor và thời điểm.
Hoàn tác trong 15 phút về trạng thái trước đó; từ chối nếu slot đã được đặt lại.
/NoShows/Create kiểm tra lịch sử khi nhập điện thoại và yêu cầu xác nhận cảnh báo ở backend khi tạo lịch mới.
Form quầy hỗ trợ một dịch vụ, kiểm tra ca làm, giờ mở cửa đã cấu hình, thời lượng và trùng lịch.
API JWT: POST /api/appointments/{id}/no-show, POST /api/appointments/{id}/undo-no-show,
GET /api/appointments/customer-warning và GET /api/appointments/occupied-slots.
Không có endpoint check-in trên nhánh này.

Kiểm thử: dotnet test SalonManagement.Tests/SalonManagement.Tests.csproj
HTTP server thật sau build: python tools/test_s3_06_http.py
SQL Server: DatabaseProvider=SqlServer và dotnet ef database update --project SalonManagement.
SQLite demo cần database mới (EnsureCreated không nâng cấp database cũ).
SQL Server/staging cần xác minh tại môi trường triển khai.
