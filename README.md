# Salon Management System - Staging & Setup Guide

Du an quan ly Salon ho tro khoi chay moi truong Staging/Development chi bang **1 lenh duy nhat**.

---

## 1. Huong dan chay ung dung (Chi 1 lenh)

Mo Terminal tai thu muc goc cua du an va chay lenh:

```bash
dotnet run --project SalonManagement
```

> **Luu y:** Lenh tren se tu dong Apply Migration, chay SeedData va tao tai khoan demo.
